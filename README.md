# 项目计划书：手机端策略 RPG 网页游戏（Streamlit 版）

## 一、 项目概述
* **项目类型**：轻量化、纯策略导向的单机 RPG 网页游戏。
* **运行环境**：手机端浏览器（针对移动端触控优化）。
* **技术栈**：Python、Streamlit、Pandas、Plotly/原生 HTML/CSS（用于手机端布局适配）。
* **核心设计理念**：
    * **抛弃传统等级/经验条**：不使用繁琐的等级膨胀，核心成长依托于**熟练度系统**与**装备构筑**。
    * **重策略与机制驱动**：敌人拥有多样化的特殊机制（护盾、蓄能、属性克制等），战斗胜负取决于配装与技能释放时机，而非单纯数值碾压。
    * **美少女伙伴收集**：敌人皆为“怪物美少女”，战胜后可消耗资源将其收复为伙伴（队伍上限 4 人：1主角 + 3伙伴）。

---

## 二、 核心系统设计

### 1. 战斗与界面布局（移动端优化）
* **视觉中心（屏幕正中间）**：
    * 展示当前挑战的 **怪物美少女立绘/背景**。
    * 附带敌人状态栏：血量、护盾值、大招蓄能进度条、当前生效的特殊机制标签。
* **下方战术区（4 个格子 / 2x2 网格）**：
    * 展示己方小队成员（主角 + 最多 3 名伙伴）。
    * 每个格子显示头像、当前 HP、Buff/Debuff 状态及当前出战选择。
* **底部操作区**：
    * 大尺寸触控按钮：`【攻击】`、`【战技】`、`【魔法】`、`【道具】`、`【更换目标/战术】`。

### 2. 成长系统：熟练度曲线（熟练度机制）
所有攻击、战技、魔法均拥有熟练度（0% 至 100%+）：
* **效果随熟练度缩放**：
    * 初始（0% 熟练度）：伤害/效果 = 基础值的 50%，命中率 = 50%。
    * 随着使用次数线性或对数提升至 100%（满效果）。
* **突破临界点（Over-mastery）**：
    * 熟练度达到 100% 后继续使用，有概率触发 **觉醒/暴击**（如 150% 伤害、双倍治疗或附加异常状态）。
* **分类**：武器熟练度、技能熟练度、魔法熟练度。

### 3. 伙伴与收复系统
* **编组限制**：最多 4 人小队（主角 + 3 个伙伴格子）。队伍满时获得新伙伴需选择“替换”或“放弃”。
* **收复机制**：战胜特定美少女 Boss 后，通过消耗道具/金钱概率收复。
* **伙伴特性**：每位收复的伙伴自带独特的被动光环或支援技能。

### 4. 装备与构筑（Build）系统
* 没有等级，装备是核心战力来源。
* 装备不仅增加基础面板，更带有 **规则改变类词缀**（例如：吸血、免疫暴击、法力回响、减速换高伤等），供玩家针对不同机制的敌人进行策略搭配。

---

## 三、 开发与迭代路线图
1. **Phase 1（UI 与框架搭建）**：实现手机端响应式布局（中间敌人立绘 + 下方 4 格小队 + 底部操作按钮）与核心状态管理（`st.session_state`）。
2. **Phase 2（战斗逻辑与熟练度系统）**：编写回合制战斗引擎，落地熟练度成长公式、命中率、伤害计算与战斗日志。
3. **Phase 3（机制怪与伙伴系统）**：设计第一个带特殊机制的怪物美少女 Boss，并实现战后收复与 4 人小队替换逻辑。
4. **Phase 4（装备与数值平衡）**：引入词缀装备系统，丰富流派构筑。
